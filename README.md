## 📚 Course Structure

The training is divided into modules that directly map to the official AZ-900 exam skills measured (updated January 2026).

### [Module 1: Describe Cloud Concepts (25-30%)](./1-CLOUD-CONCEPTS/README.md)
* Understand cloud computing fundamentals
* Learn the benefits of using cloud services
* Differentiate between cloud service types (IaaS, PaaS, SaaS)

### [Module 2: Describe Azure Architecture and Services (35-40%)](./2-AZURE-ARCHITECTURE/README.md)
* Explore core architectural components of Azure
* Discover Azure compute and networking services
* Understand Azure storage services
* Learn about Azure identity, access, and security

### [Module 3: Describe Azure Management and Governance (30-35%)](./3-MANAGEMENT-GOVERNANCE/README.md)
* Master cost management in Azure
* Understand governance and compliance features
* Learn tools for managing and deploying Azure resources
* Explore monitoring tools in Azure
