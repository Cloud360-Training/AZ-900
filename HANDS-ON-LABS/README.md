# Hands-On Labs & Sandbox Exercises

Practical experience is essential for understanding Azure concepts and passing the AZ-900 exam. This section provides guidance on how to access free lab environments and outlines key exercises to complete.

## 🧪 Microsoft Learn Sandbox

The Microsoft Learn Sandbox provides a free, temporary Azure environment where you can practice deploying and managing resources without needing a credit card.

### How to Access the Sandbox
1. Navigate to any Microsoft Learn module that includes a hands-on exercise (e.g., [Create a virtual machine](https://learn.microsoft.com/en-us/training/modules/create-windows-virtual-machine-in-azure/3-exercise-create-a-vm)).
2. Sign in with your Microsoft account.
3. Click the **Activate sandbox** button.
4. Review the permissions and accept.
5. You will have a set amount of time (usually 1-4 hours) to use the sandbox environment.

## 📝 Recommended Lab Exercises

These exercises align with the AZ-900 exam objectives and provide practical experience with core Azure services.

### Lab 1: Create a Virtual Machine
* **Objective**: Deploy a Windows or Linux virtual machine using the Azure portal.
* **Microsoft Learn Guide**: [Exercise - Create a Windows virtual machine](https://learn.microsoft.com/en-us/training/modules/create-windows-virtual-machine-in-azure/3-exercise-create-a-vm)
* **Key Skills**: Selecting VM sizes, configuring networking, connecting via RDP/SSH.

### Lab 2: Configure a Virtual Network
* **Objective**: Create a virtual network and subnets to isolate resources.
* **Microsoft Learn Guide**: [Exercise - Design and implement a virtual network](https://learn.microsoft.com/en-us/training/modules/design-implement-virtual-network/)
* **Key Skills**: Defining address spaces, creating subnets, understanding network security groups (NSGs).

### Lab 3: Create a Storage Account
* **Objective**: Provision an Azure Storage account and upload a blob.
* **Microsoft Learn Guide**: [Exercise - Create a storage account](https://learn.microsoft.com/en-us/training/modules/create-azure-storage-account/5-exercise-create-a-storage-account)
* **Key Skills**: Selecting storage tiers, configuring redundancy, managing access keys.

### Lab 4: Estimate Costs with the Pricing Calculator
* **Objective**: Use the Azure Pricing Calculator to estimate the cost of a solution.
* **Microsoft Learn Guide**: [Exercise - Estimate workload costs using the Pricing calculator](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/3-exercise-estimate-workload-costs-using-pricing-calculator)
* **Key Skills**: Adding resources to an estimate, adjusting parameters, exporting estimates.

### Lab 5: Apply Resource Locks and Tags
* **Objective**: Implement governance by applying locks and tags to resources.
* **Microsoft Learn Guide**: [Exercise - Apply resource locks](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-azure-governance-compliance/5-exercise-apply-resource-locks)
* **Key Skills**: Creating read-only and delete locks, defining tag name/value pairs.
