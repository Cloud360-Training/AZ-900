# Module 2: Describe Azure Architecture and Services (35-40%)

This module dives into the core architectural components of Azure and the primary services it offers. It represents the largest portion of the AZ-900 exam.

## 📖 Microsoft Official Documentation & Learn

### 1. Core Architectural Components
* **Microsoft Learn Path**: [Describe core Azure architectural components](https://learn.microsoft.com/en-us/training/modules/describe-core-architectural-components-of-azure/)
* **Key Topics**:
  * Azure regions, region pairs, and sovereign regions
  * Availability zones and datacenters
  * Azure resources and resource groups
  * Subscriptions and management groups
  * The hierarchy of resource organization

### 2. Compute and Networking Services
* **Microsoft Learn Path**: [Describe Azure compute and networking services](https://learn.microsoft.com/en-us/training/modules/describe-azure-compute-networking-services/)
* **Key Topics**:
  * Compute types (Containers, VMs, Functions)
  * Virtual machine options (VMs, Scale Sets, Availability Sets, Azure Virtual Desktop)
  * Application hosting options (Web apps, containers, VMs)
  * Virtual networking (VNet, subnets, peering, DNS, VPN Gateway, ExpressRoute)
  * Public and private endpoints

### 3. Azure Storage Services
* **Microsoft Learn Path**: [Describe Azure storage services](https://learn.microsoft.com/en-us/training/modules/describe-azure-storage-services/)
* **Key Topics**:
  * Comparing Azure Storage services
  * Storage tiers and redundancy options
  * Storage account options and types
  * Moving files (AzCopy, Storage Explorer, File Sync)
  * Migration options (Azure Migrate, Data Box)

### 4. Identity, Access, and Security
* **Microsoft Learn Path**: [Describe Azure identity, access, and security](https://learn.microsoft.com/en-us/training/modules/describe-azure-identity-access-security/)
* **Key Topics**:
  * Directory services (Microsoft Entra ID, Entra Domain Services)
  * Authentication methods (SSO, MFA, passwordless)
  * External identities and Conditional Access
  * Role-Based Access Control (RBAC)
  * Zero Trust and defense-in-depth models
  * Microsoft Defender for Cloud
