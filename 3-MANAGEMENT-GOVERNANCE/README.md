# Module 3: Describe Azure Management and Governance (30-35%)

This module focuses on how to manage, govern, and monitor your Azure environment effectively, ensuring compliance and cost efficiency.

## 📖 Microsoft Official Documentation & Learn

### 1. Cost Management in Azure
* **Microsoft Learn Path**: [Describe cost management in Azure](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/)
* **Key Topics**:
  * Factors affecting costs in Azure
  * Using the Pricing Calculator
  * Cost management capabilities
  * The purpose and use of resource tags

### 2. Governance and Compliance
* **Microsoft Learn Path**: [Describe features and tools in Azure for governance and compliance](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-azure-governance-compliance/)
* **Key Topics**:
  * Microsoft Purview in Azure
  * Azure Policy
  * Resource locks

### 3. Managing and Deploying Resources
* **Microsoft Learn Path**: [Describe features and tools for managing and deploying Azure resources](https://learn.microsoft.com/en-us/training/modules/describe-features-tools-managing-deploying-azure-resources/)
* **Key Topics**:
  * The Azure portal
  * Azure Cloud Shell (CLI and PowerShell)
  * Azure Arc
  * Infrastructure as Code (IaC)
  * Azure Resource Manager (ARM) and ARM templates

### 4. Monitoring Tools
* **Microsoft Learn Path**: [Describe monitoring tools in Azure](https://learn.microsoft.com/en-us/training/modules/describe-monitoring-tools-azure/)
* **Key Topics**:
  * Azure Advisor
  * Azure Service Health
  * Azure Monitor (Log Analytics, Alerts, Application Insights)
