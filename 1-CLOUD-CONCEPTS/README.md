# Module 1: Describe Cloud Concepts (25-30%)

This module covers the fundamental concepts of cloud computing. It is the foundation upon which all other Azure knowledge is built.

## 📖 Microsoft Official Documentation & Learn

### 1. Describe Cloud Computing
* **Microsoft Learn Path**: [Introduction to cloud computing](https://learn.microsoft.com/en-us/training/modules/describe-cloud-compute/)
* **Key Topics**:
  * Define cloud computing
  * Describe the shared responsibility model
  * Define cloud models (Public, Private, Hybrid)
  * Identify appropriate use cases for each cloud model
  * Describe the consumption-based model
  * Compare cloud pricing models
  * Describe serverless computing

### 2. Describe the Benefits of Using Cloud Services
* **Microsoft Learn Path**: [Describe the benefits of using cloud services](https://learn.microsoft.com/en-us/training/modules/describe-benefits-use-cloud-services/)
* **Key Topics**:
  * High availability and scalability
  * Reliability and predictability
  * Security and governance
  * Manageability in the cloud

### 3. Describe Cloud Service Types
* **Microsoft Learn Path**: [Describe cloud service types](https://learn.microsoft.com/en-us/training/modules/describe-cloud-service-types/)
* **Key Topics**:
  * Infrastructure as a Service (IaaS)
  * Platform as a Service (PaaS)
  * Software as a Service (SaaS)
  * Use cases for IaaS, PaaS, and SaaS
